# TaskFlow

TaskFlow is a task management application built with React and Vite. This project is part of my React learning journey, where I'm building the application step by step while learning React fundamentals.

## 🚀 Tech Stack

- React
- Vite
- JavaScript

## 📌 Current Features

- Reusable Navbar component
- Task input UI

## 🛠️ Getting Started

1. Clone the repository

```bash
git clone <repository-url>
```

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm run dev
```
